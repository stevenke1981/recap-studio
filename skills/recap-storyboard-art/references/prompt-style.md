# 圖像提示詞風格範本（recap-storyboard-art）

本檔為 `recap-storyboard-art` 的附錄。風格前綴與角色描述存於 `01_outline/outline.md` 之「圖像風格聖經」區塊，全片固定；單組提示詞由下列四段組成。

## 1. 風格聖經（寫入 outline.md）

```markdown
## 圖像風格聖經

### 全片風格前綴（逐字固定）
{STYLE_PREFIX}

### 色調與光線
- 主色調：{PALETTE}
- 光源：{LIGHTING}

### 畫幅
16:9 寬銀幕構圖，1920×1080。

### 全片負面提示（逐字固定）
{NEGATIVE}
```

### 通用負面提示（所有片型共用）

```
避免：文字、字幕、水印、浮水印、logo、品牌標誌、簽名、畫框邊、多餘的手指或肢體、扭曲的臉、過度磨皮、過曝、卡通化、漫畫網點、動畫截圖感、3D 遊戲建模感、現代招牌（古代題材）、現代服飾（古代題材）
```

## 2. 單組提示詞範本

```
{STYLE_PREFIX}
{CHARACTERS}
{SCENE}
{SHOT}
{NEGATIVE_LINE}
```

| 欄位 | 來源 | 寫法 |
|---|---|---|
| `STYLE_PREFIX` | outline 風格聖經 | 全片一字不改 |
| `CHARACTERS` | outline 人物表之「外觀固定描述」 | 只寫本組出場者；每人一句，逐字取用 |
| `SCENE` | 旁白改寫為視覺 | 地點、時辰、天氣、人物動作、道具；不寫對白、不照抄旁白 |
| `SHOT` | 人工判斷 | 構圖詞：特寫／中景／全景、俯角／平角、景深；不寫運鏡（運鏡由 motion 控制） |
| `NEGATIVE_LINE` | 負面提示 | 以「避免：」起頭，附於末尾 |

長度：建議 120–220 字（中文）或同等英文，過長的細節會被工具忽略。

## 4. 維護

- 風格前綴一經定案即全片固定；中途改風格需整片重生，須主控同意。
- 換角色外觀須同步改 outline 人物表，並重生所有含該角色的組。
- 示例中的人物與情節皆為原創示意，不指涉任何既有作品或真實人物。
