# 口播稿審稿檢查清單

審稿者宜為未寫該章的另一代理。每項填 通過／不通過＋位置（`chNN.pMM`，與 `script_stats.py` 輸出一致）。不通過項退回改寫，改完重跑 `script_stats.py` 與 `script_to_shots.py`。

先跑量測：
```
python <repo>\skills\recap-script-writer\scripts\script_stats.py <repo>\projects\<slug>
python <repo>\scripts\script_to_shots.py <repo>\projects\<slug>
```

## A 閘門數值
- [ ] `script_to_shots.py` exit 0；`est. duration` 在目標 ±10%
- [ ] 總字數與 `target_minutes × 250` 偏差 ≤5%；各章與骨架預算偏差 ≤15%
- [ ] `script_stats.py` 無 FAIL；WARN 皆已處理或註明原因
- [ ] 章數與級制符合 SKILL.md 預算表（±2 章）；章名皆 ≤12 字
- [ ] 若已有實測 cpm（voice-subs 回報）：偏離 250 逾 8% 者已重算預算

## B 事實
- [ ] 人名、地名、年代、事件與 outline 一致；outline 沒有的未被杜撰
- [ ] 因果方向正確（誰導致誰），未把巧合寫成必然
- [ ] 結局與關鍵反轉與原作一致
- [ ] 評論中的「與現實對照」有 `note: 查證` 出處，且可查
- [ ] 史料或情節有歧見處，稿中明說，未編成定論
- [ ] 公版作品的戲劇化增寫皆標 `增寫`，且未與原作矛盾
- [ ] 冷開場所預告的「代價」確實在正文兌現；標題縮圖承諾已兌現
- [ ] 所有 `待查` 標記已清零

## C 連貫性八類錯誤
依 BooookScore 八類（見 research/02 第 1.1 節），逐類檢查整份稿。

| 類別 | 稿中症狀 | 檢查法 |
|---|---|---|
| 實體省略 | 人物或物件突然出現，未交代身份 | Grep 每個人名，確認首次出現附身份；長片每章首次提及有回指 |
| 事件省略 | 角色已知某事，但稿中從未講過 | 對照 outline 事件鏈，補一句橋接 |
| 因果省略 | A 之後直接 C，少了 B | 逐章列「因為→所以」鏈，斷處補句 |
| 不連貫 | 場次之間跳躍，轉折語缺失 | 讀每章首尾；確認承接句與鉤子 |
| 顯著性 | 塞入與主線無關的細節，拖慢節奏 | 每個場次問：刪掉後觀眾看得懂嗎？看得懂就刪 |
| 語言 | 代名詞指涉不明、語病、書面腔 | 朗讀；「他」超過兩個可能指涉者改名字 |
| 前後矛盾 | 年齡、時間、數量、稱謂前後不一 | 對風格表與時間線錨點逐項核；Grep 稱謂的所有寫法 |
| 重複 | 同一資訊、比喻、句型、論點反覆 | Grep 高頻詞與句首；相鄰章鉤子型別不同 |

另加跨章三項：
- [ ] 知識邊界：角色未說出他當時不知道的事
- [ ] 伏筆帳本：埋與收一一對應
- [ ] 每章第一句承接上章鉤子，鉤子在其後 2 章內兌現

## D 口播可讀性
- [ ] 朗讀一遍（或 TTS 試聽）無須回頭重讀才懂
- [ ] 單句 ≤30 字；沒有 >`segment_max_chars` 的句子
- [ ] 段長 30–120 字；極短段（<12 字）每章 ≤3
- [ ] 無長定語堆疊；無「首先／其次／綜上所述」
- [ ] 無阿拉伯數字、英文字母、括號、破折號、半形標點（或已登記處理）
- [ ] 年份逐位念法；量詞前「兩」；百分比、單位中文化
- [ ] 句中無「…」誤切；「…」僅用於刻意停頓且置於句末
- [ ] 無舞台指示（停頓、笑、音效）混入旁白
- [ ] 無 Markdown 符號被念出（行首 `-`、`>`、`---`、`**`、反引號、表格）
- [ ] 人物首次出現附身份，且寫進句中
- [ ] 同音易誤聽處已處理（他／她、角色名同音、「妻」與「七」類）
- [ ] 高風險多音字已改寫避開，或登記於 `pron_candidates.md`
- [ ] 每 60–90 秒（約 250–375 字）有節奏變化；每 3–5 分鐘有小懸念
- [ ] 每章末句為鉤子；相鄰章鉤子型別不同；全片同型 ≤30%
- [ ] 重要場景段首有 `<!-- image: -->`，只寫畫面內容

## E 評論比重估算
1. 以 `note: 評論` 標記後執行 `script_stats.py`，讀「commentary」行與各章 `評論%`。
2. 人工抽查標記是否誠實：逐一確認被標評論的段落具備**論點＋依據＋意義**；純感嘆、純複述、預告不計。
3. 未標記但實為評論者，補標記；混寫段拆開再標。
4. 判定：
   - [ ] 全片 ≥30%（高風險作品 ≥50%）
   - [ ] 每章 ≥1 段（冷開場可免）
   - [ ] 無「純複述」章
   - [ ] 評論分布：設定、中段回顧、收束三處皆有，且不全擠在結尾
   - [ ] 評論類型多樣（動機分析、伏筆、現實對照、手法評析、主題），未反覆同一論點

## F 版權與合規（CP-2）
- [ ] 逐字引文總計 ≤2–3 句、短語級，且記有 `<!-- note: 引文｜出處 -->`
- [ ] 對白、描寫、金句皆已改寫；未保留原作獨有修辭長段
- [ ] 結構依因果而非照搬原作章節；未達「用自己的話逐場景重述全書」
- [ ] 關鍵反轉與文字魅力有所保留，結局以評價式呈現（受保護作品）
- [ ] 設定段或片頭報作品名、作者、出版方；收束導流正版（受保護作品）
- [ ] CP-1 風險等級已記在 `skeleton.md` 檔頭，與評論門檻一致
- [ ] 公版增寫已標記，供說明欄聲明「非原文逐字」
- [ ] 稿中無仿冒真人聲音、誹謗或針對私人的內容
- [ ] 與前作比較（CP-5）：結構、句型、鉤子型別、意象不與前 4 支片雷同，有獨有觀點
