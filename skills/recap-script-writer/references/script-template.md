# script.md 範本

用法：複製下方「範例」區塊整段為 `02_script/script.md`，換成自己的內容；或複製「空白骨架」區塊起手。
範例改寫自公版《聊齋志異・畫皮》（蒲松齡，清），為原創白話口播稿，非原文逐字；僅示範格式、節奏與評論層寫法，不含全篇。
區塊內一切非註解、非 `#` 行的文字都會被念出，因此不可混入說明、項目符號或分隔線。

## 標記約定（皆為 HTML 註解，不念）

| 標記 | 用途 | 誰讀 |
|---|---|---|
| `<!-- image: 場景描述 -->` | 套用至下一段之圖像提示詞；只寫畫面內容，不寫統一畫風前綴（前綴由 recap-storyboard-art 加） | script_to_shots.py |
| `<!-- note: 評論 -->` | 緊貼其後之一段計入評論字數；`評論×3` 表接下來三段；可接說明，如 `note: 評論×3｜人物動機` | script_stats.py |
| `<!-- note: 增寫 -->` | 公版作品之戲劇化增寫段，供說明欄揭露「非原文逐字」 | script_stats.py |
| `<!-- note: 場次 2.1｜功能｜約 45 秒 -->` | 兩級結構之場次標記（任意文字） | 人類 |
| `<!-- note: 查證 …… -->` | 現實對照／史實之出處 | 人類、審稿 |

規則：標記獨占一行，前後各留一個空行（避免與旁白黏成同段）；`image` 註解會截斷前一段。

## 範例（可直接複製）

```markdown
# 一口氣看完《畫皮》：他只多看了一眼

## 集市上的那口痰
<!-- note: 冷開場｜倒敘結局意象＋觀點承諾｜約 40 秒 -->

<!-- image: 清晨的古代集市，人群圍成一圈，泥地中央跪著一個衣衫凌亂的婦人，面前蹲著滿身髒污的乞丐 -->
集市中央，圍了一圈人。

圈子裡，跪著一個婦人。她面前蹲著一個乞丐，渾身發臭，正笑嘻嘻地看著她。

乞丐咳了一聲，吐出一口濃痰，說：「想救他，就把這個吃下去。」

婦人的臉漲得通紅。她咬了咬牙，還是低下頭，把那口痰吞了下去。

一個女人，為什麼肯做到這一步？因為她丈夫胸口那個位置，已經空了。

<!-- note: 評論｜觀點承諾 -->

三百年來，這個故事一直被當成鬼故事。可它真正嚇人的地方不在鬼，在把她推到這一步的那個念頭。

那個念頭，只花了一個書生三秒鐘。故事要從幾天前的一個清晨說起。

## 巷口遇見的姑娘
<!-- note: 場次 2.1｜引入主角與誘因｜約 100 秒 -->

<!-- image: 天剛亮的城中小巷，一名書生停步回望，前方有個抱著包袱的年輕姑娘，背影單薄 -->
王生是太原城裡的讀書人，家境普通。妻子陳氏賢慧，日子過得安穩。

那天他天沒亮就出門，在巷口遇見一個獨自趕路的姑娘。她大約十六歲，抱著一個包袱，走得很慢。

王生上前問：「姑娘，天還沒亮，你一個人要去哪？」

姑娘低著頭說，爹娘貪財，把她賣去給人做妾。大婦又兇，天天打罵，她受不了，才逃出來。

她說她無處可去。王生心一軟，也有一點別的心思。他說：「我家有間空書房，你先住下，別讓人知道。」

<!-- note: 評論×3｜人物動機分析 -->

先停一下。這是整個故事的第一個轉折，也是最容易被略過的地方。

王生沒問她的名字，也沒問她的來歷。他甚至沒想過：一個十六歲的姑娘，為什麼天沒亮就在街上？他看見的不是一個人，是一個機會。

清代作家蒲松齡在這裡不寫妖氣，只寫人心。這是整篇最鋒利的一刀。

<!-- note: 場次 2.2｜妻子的警告與埋伏筆｜約 70 秒 -->

王生把她安頓在書房，鎖上門，每天往來其中。

陳氏很快聽到風聲。她沒有吵，只是私下勸他：「這女子來路不明，不如送走。」

王生不耐煩地擺擺手，說她多心。

<!-- note: 增寫｜陳氏神情，原文無 -->

陳氏看著他的背影，沒有再說話。她只是記住了那間書房的位置。

這句勸告，王生沒放在心上。可後來他會明白，整個故事裡，只有陳氏一個人，一直是清醒的。

幾天之後，王生從門縫裡，看見了一張臉。那張臉，不屬於任何一個活人。

<!-- note: 此處省略中間各章；實際稿中每章皆須有標題、鉤子與至少一段評論 -->

## 回到那個清晨
<!-- note: 收束｜回扣開場意象＋主題＋留言問題＋導流｜約 120 秒 -->

<!-- image: 回到開場的集市，鏡頭拉遠，婦人低頭吞下痰的背影，周圍人群沉默 -->
現在，我們回到開頭那個集市。

陳氏跪在泥地裡，吞下那口痰的時候，她想的不是尊嚴。她想的是，丈夫還能不能再喊她一聲。

<!-- note: 評論×3｜主題昇華 -->

說到底，害人的東西，故事裡很快就被收拾了。真正沉重的，是後面那筆帳。

一個人因為多看了一眼，丟了最重要的東西。另一個人，為了替他討回來，連臉面都押上去。蒲松齡寫的從來不只是鬼怪。他寫的是：人的欲望一旦沒有分寸，連最親近的人也要替他付帳。

如果你是王生，天亮的巷口，你會停下來問一句嗎？還是和他一樣，只看見眼前的好運？

原作〈畫皮〉收在《聊齋志異》裡。篇幅不長，文字很有味道，推薦你找來讀一讀。

留言告訴我你的答案。這裡是夜燈說書，我們下回見。
```

## 長片「中段回顧」示範段（插在章首，約 50 至 100 字）

先替剛點進來的朋友，用一句話說清楚現在的局面。王生性命垂危，陳氏孤身一人，而那個東西，還躲在這個家裡。

到這裡，我們走過兩件事：他怎麼遇見她，又怎麼發現她不是人。接下來的問題只有一個：誰能救他。
